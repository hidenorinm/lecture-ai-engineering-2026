## 宿題
### 取り組んだレベル：実装
- やったこと：
  - `app/ask.py` に `--chat` オプションを追加し、会話履歴を保ったまま続けて質問できるようにした
  - Claude API は前の会話を覚えていないため、それまでの質問と回答を `history` に貯め、毎回まとめて `messages` として送り直す
  - `ask()` に省略可能な引数 `history` を足した。渡さなければ今までどおりの単発の質問になる。
  - Claude Code（VS Code 拡張）に条件（既存の使い方を変えない、`--chat` のときだけ会話モード、エラーの回は履歴に残さない、変更は ask.py だけ）を付けて依頼し、差分を読んで確認してから採用した。
- 結果（モデル：claude-haiku-5-5）：

  | | 2問目「それを使うメリットを3つに絞って」への回答 | 入力トークン | 出力トークン |
  |---|---|---|---|
  | 会話モード（1問目「LoRAとは何ですか？」の後） | LoRA のメリットを3つに絞って回答 | 801 | 220 |
  | 単発（履歴なし） | 「それ」が何を指すのか聞き返した | 22 | 181 |

  - 会話モードの1問目は 入力 19 / 出力 766
- 気づき：
  - 履歴を送り直すことで、「それ」のような前の話を受けた質問が通じた
  - 2問目の入力 801 は、1問目の質問と回答、2問目の質問を合わせた量にほぼ一致した。会話が続くほど毎回送るトークンが増え、費用と応答時間が増える
  - 長い会話では、古い履歴を削る・要約するなどの工夫が必要か
